## 实际限制

- 目录能力是逐文件审查和汇总，不是完整跨文件分析。
- AST 规则覆盖有限，资源关闭判断不能证明所有控制流路径都正确。
- 模型新增发现保持待确认；缺乏确定验证依据时，不自动关闭。
- 修复预览仅验证原片段匹配和 Python 语法，业务语义需人工确认。
- Monaco 编辑器使前端主包约 3.7 MB（gzip 约 1 MB）；资源本地提供，首次打开有加载开销。
- 自动化验证环境为 macOS、Python 3.14、Node.js 24；尚未单独进行 Windows 平台验收。
