# 一分钟演示脚本

录制前启动工作台，先打开 `examples/demo_project`，填好 API Key 并做一次审查。模型等待时间不固定，录屏时可以使用已保存的结果和执行记录；不要将 Fake LLM 结果称为真实模型审查。

| 时间 | 操作与讲解 |
|---|---|
| 0–10 秒 | 展示文件列表与审查要求：“这是面向 Python 小项目的代码审查 Agent，支持目录和单文件。” |
| 10–25 秒 | 展示三文件审查结果，点击可变默认参数问题，定位源码：“每个问题包含位置、工具证据、建议；已证实和待确认分别标记。” |
| 25–35 秒 | 展开执行过程：“先读文件和 AST 检查，模型再选择工具、观察并汇总；会话与结果保存在本地。” |
| 35–45 秒 | 打开修复预览：“展示修改前后差异，复制或下载补丁，用户手动修改源码。” |
| 45–55 秒 | 展示已经完成的复查：“对应规则验证通过才关闭问题，失败或证据不足保留待确认；历史快照不被修改。” |
| 55–60 秒 | 点击历史与报告下载：“支持追问、历史审查和 Markdown / JSON 报告，CLI 仍可使用。” |

演示复查前请先把 `cart.py` 的建议应用到单独的项目副本。原始演示目录保持带缺陷状态，便于下一次演示；修复参考在 `examples/fixed_project`。
